# W9 预习：我希望助手拥有的两个工具

> 作业 3 的第二半。要求写清每个工具**输入什么、输出什么**——工具调用的本质就是「给模型一份能照着填的说明书」。

## 工具 1：查生词表 `lookup_vocab`

**解决什么问题**：学生问「『献疑』是什么意思」，模型会编；如果助手能查我课上的词表，就能给准确释义和例句。

| 项 | 内容 |
|---|---|
| 工具名 | `lookup_vocab` |
| 输入 | `word`（字符串，如「亡以应」）；可选 `level`（默认 HSK4） |
| 输出 | JSON：`{"word": "...", "pinyin": "...", "meaning": "...", "example": "...", "found": true/false}` |
| 数据来源 | `week07_RAG/data.txt` 里的【教学标注·词汇】那 9 个词，或单独维护一份 `vocab.json` |
| 找不到时 | 返回 `{"found": false}`，而不是让模型猜 |
| 为什么要它 | 查词是高频动作，也是 W7「资料里没有就说没有」的自然延伸 |

## 工具 2：算分 `score_quiz`

**解决什么问题**：我出 10 道题，学生做完要算分、换算成 HSK 等级。让模型心算容易错，交给函数最稳。

| 项 | 内容 |
|---|---|
| 工具名 | `score_quiz` |
| 输入 | `answers`（列表，如 `["A","B","C","D"]`）、`answer_key`（列表，如 `["A","B","A","D"]`）、可选 `total_score`（默认 100） |
| 输出 | JSON：`{"correct": 3, "total": 4, "score": 75.0, "wrong_items": [3]}` |
| 边界 | 长度不一致直接报错，不猜；空列表返回 0 分并提示 |
| 为什么要它 | 数字计算必须可复现；也让模型从「算」里解放出来，专心讲错题 |

## 我的判断：什么时候该给模型工具

1. **答案在外部数据里**（词表）→ 必须给，否则就是幻觉；
2. **答案要精确计算**（分数）→ 最好给，模型算术不可靠；
3. **纯生成**（写评语、设计活动）→ 不用给，模型自己写得更好。

这条判断和 W7 的 RAG 边界是同一个逻辑：**先问「这个答案该从哪来」，再决定是查、是算、还是让模型写。**

【示例】
### 一、语法公式
* **结构公式**：主语 + 把 + 宾语 + 动词 + 其他成分（了/完/在...）
* **否定形式**：主语 + 没有 + 把 + 宾语 + 动词 + 其他成分
* **能愿动词位置**：主语 + 能愿动词（想/要/能）+ 把 + 宾语 + 动词 + 其他成分

### 二、场景讲解
* **使用条件**：强调对已知事物的处置或产生影响（如：位移、改变状态）。
* **场景例句**：
  1. 我把书放在桌子上了。（强调“书”的位置改变）
  2. 妹妹把苹果吃完了。（强调“苹果”的状态改变）
  3. 他**没有**把作业做完。（否定形式：强调没完成）
  4. 你**能**把窗户打开吗？（能愿动词：表示请求）

### 三、分层练习
**1. 机械练习（连词成句）：**
| 题号 | 词语组合 | 答案 |
| :--- | :--- | :--- |
| 1 | 我 / 把 / 作业 / 做完了 / 。 | 我把作业做完了。 |
| 2 | 妈妈 / 把 / 衣服 / 洗 / 干净 / 了 / 。 | 妈妈把衣服洗干净了。 |

**2. 交际练习（情景造句）：**
| 题号 | 情景提示 | 参考答案 |
| :--- | :--- | :--- |
| 1 | 朋友来你家，你觉得很热，想让他开空调。 | 你能把空调打开吗？ |
| 2 | 你吃完晚饭，告诉妈妈你收拾了碗筷。 | 我把碗筷收拾好了。 |

### 四、答案与解析
* **机械练习解析**：
  1. “做完了”满足“把”字句动词后必须带其他成分的规则。
  2. “洗干净了”使用结果补语，强调“衣服”的变化结果。
* **交际练习解析**：
  1. 使用能愿动词“能”，表示请求，语序正确。
  2. 使用“动词+好了”结构，表示完成并达到妥善状态。

### 五、错误预警（教师提示）
* **常见偏误1**：学生容易说“我把作业做了完。”（错）
  * **纠错建议**：强调“了”的位置应在动词后的补语之后，如“做完了”。
* **常见偏误2**：学生容易说“我把书没看完。”（错）
  * **纠错建议**：强调否定词“没”必须放在“把”字之前，即“我没把书看完”。

【示例】
### 一、语法公式
* **把字句公式**：主语 + 把 + 宾语 + 动词 + 其他成分（了/完/在...）
* **被字句公式**：主语 + 被 + 宾语 + 动词 + 其他成分（了/完/在...）
* **互换规则**：A把B+动词+结果 ⇌ B被A+动词+结果

### 二、场景讲解
* **使用条件**：
  * “把”字句强调对已知事物的处置（A对B做了什么）。
  * “被”字句强调主语受到的影响（B被A怎么样了）。
* **场景例句**：
  1. 我把书放在桌子上了。（强调“书”的位置改变）
  2. 书被我放在桌子上了。（强调“书”被处置的结果）
  3. 妹妹把苹果吃完了。（强调“苹果”的状态改变）
  4. 苹果被妹妹吃完了。（强调“苹果”受到的影响）

### 三、分层练习
**1. 机械练习（连词成句）：**
| 题号 | 词语组合 | 答案 |
| :--- | :--- | :--- |
| 1 | 我 / 把 / 作业 / 做完了 / 。 | 我把作业做完了。 |
| 2 | 窗户 / 被 / 弟弟 / 打开了 / 。 | 窗户被弟弟打开了。 |

**2. 交际练习（情景造句）：**
| 题号 | 情景提示 | 参考答案 |
| :--- | :--- | :--- |
| 1 | 朋友来你家，你觉得很热，想让他开空调。（用“把”字句） | 你能把空调打开吗？ |
| 2 | 你吃完晚饭，告诉妈妈碗筷已经收拾好了。（用“被”字句） | 碗筷被我收拾好了。 |

### 四、答案与解析
* **机械练习解析**：
  1. “做完了”满足“把”字句动词后必须带其他成分的规则。
  2. “被弟弟打开了”满足“被”字句主语是受事者的规则。
* **交际练习解析**：
  1. 使用能愿动词“能”，表示请求，语序正确。
  2. 使用“被+施事者+动词+好了”结构，表示完成并达到妥善状态。

### 五、错误预警（教师提示）
* **常见偏误1**：学生容易说“我把作业做了完。”（错）
  * **纠错建议**：强调“了”的位置应在动词后的补语之后，如“做完了”。
* **常见偏误2**：学生容易说“书被放了在桌子上。”（错）
  * **纠错建议**：强调“被”字句中，介词短语“在桌子上”应在动词之后，即“书被放在桌子上了”。
